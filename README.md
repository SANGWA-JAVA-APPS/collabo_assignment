# SANGWA Emmanuel — Software Engineer Portfolio

A responsive, multi-page portfolio website showcasing the software engineering services, projects, and contact information of SANGWA Emmanuel.

## About the Project

This website introduces SANGWA Emmanuel as a software engineer and highlights practical software solutions for business operations. Visitors can learn about available services, browse recent software projects, read sample client testimonials, and get in touch to discuss a project.

## Website Pages

- **Home** — Introduction, featured software projects, and client testimonials.
- **About** — Background and professional information.
- **Services** — Business software, web and mobile applications, system integration, and related services.
- **Portfolio** — A gallery of recent software projects.
- **Portfolio Details** — Additional project information.
- **Contact** — Contact details and a way to discuss a project.
- **Blog and Elements** — Additional template pages.

## Technologies

- HTML5
- CSS3
- Bootstrap
- JavaScript and jQuery
- Owl Carousel
- Font Awesome

## Getting Started

This is a static website. To view it, open `index.html` in a web browser. For a more reliable local preview, serve the project folder with a local development server.
